## The Really Cool Todo App

This is a todo list app built by following Ardit Sulce's Python course on Udemy.

The course can be accessed on https://www.udemy.com/course/the-python-mega-course

**How to use the app (widget version)** 

- Open the app by clicking on the "Really Cool Todo App" icon
- To add a todo, type it in the input bar and click on the "Add" button
- To edit a todo:
-   click on the todo you want to edit; it will be copied onto the input bar
-   write in the input bar the edited todo
-   click "Edit"
- To mark a todo as complete (and remove it):
-   click on the todo
-   click on "Complete"
- To exit, click on the "Exit" button

**How to use the app (web version)**

- Open the app by running the following command on the Terminal from the todoApp directory: `streamlit run web.py`
- To add a todo, click on the "Add +" button, type the todo in the input bar that appears below the button, and press Enter
- To mark a todo as done, simply tick the corresponding box
